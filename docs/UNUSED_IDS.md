## Why These Gaps Exist

The gaps resulted from the corpus consolidation process:

1. **Personal-only entries** (ATH-090 to ATH-126 in personal corpus) — these entries only exist in the personal corpus
2. **Entries with personal equivalents** — when public corpus entries were consolidated to personal corpus IDs, the original public IDs were replaced with the personal IDs (e.g., public ATH-017 was consolidated to personal ATH-049)

This ID consolidation ensures that the same fundamental accessibility defect has the same ID across both corpuses, while allowing public-specific entries to have new unique IDs (ATH-127+).
