# i18n Locale Files

This directory contains locale data files (JSON) for 59+ languages supported by a11yfred.

Each `.json` file follows the pattern `{key: "translated string"}` and is loaded at runtime via the `@ulam/calamansi` i18n provider.

For framework documentation, see [@ulam/calamansi](https://github.com/a11yfred/ulam).
